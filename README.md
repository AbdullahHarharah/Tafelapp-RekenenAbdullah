# Tafelapp – Rekenen

## Over het project

Dit project is een interactieve rekentool waarmee je de tafels van vermenigvuldiging kunt oefenen.

De applicatie bestaat uit twee onderdelen:

### 1. Tafels bekijken

In het middelste gedeelte kun je een tafel invoeren, bijvoorbeeld tafel 7. Vervolgens kun je de volledige tafel van 7 bekijken.

### 2. Tafels oefenen

Aan de linkerkant vind je een oefengedeelte. Hier kun je de tafel oefenen die je wilt leren.

**Hoe werkt het?**

1. Vul in het middelste gedeelte het tafelnummer in, bijvoorbeeld 7.
2. Ga naar het oefengedeelte aan de linkerkant.
3. Klik op de knop **Go**.
4. De applicatie geeft willekeurige getallen tussen 1 en 10.
5. Je kunt oefenen met de tafel van 7 door de vermenigvuldigingen te beantwoorden.

## Doel van het project

Het doel van dit project is om op een eenvoudige en interactieve manier de tafels van vermenigvuldiging te leren en te oefenen.
